052D SLAMICRA 2016

Real-Time Loop Closure in 2D LIDAR SLAM

Wolfgang Hess, Damon Kohler, Holger Rapp, Daniel Andor

局所的なサブマップを構築し、scan-to-submapの照合を用いてループ閉じ込みを処理する2D LiDAR SLAM。大きな環境でもリアルタイムに地図の整合を保つための手法を示します。

このプロジェクトとの関係

接続する点：Cartographerによる観測の位置合わせと局所地図を理解する基礎。MPPIはその観測を使った占有判定へ接続します。

限界：SLAMの利用だけでは、走行可能領域の意味や移動物の未来を判断できません。地図精度・時刻一致・未知領域の扱いは、この環境で別途検証します。

多眼の視覚オドメトリとの関係

StreamRigは校正済みの多眼画像から相対姿勢を逐次推定する研究です。CartographerのLiDARによる地図整合やloop closureとは役割・入力が異なり、置き換えによる改善は本プロジェクトで未検証です。学習split、尺度補正、欠損区間のGT接続を含む比較条件は個別記事へ整理しました。2026-10-02、関連記事を追加しました。
