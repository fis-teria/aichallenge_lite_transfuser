Smooth MPPI：操作の変化を探索し、予測の中で滑らかにする

Taekyung Kim、Gyuhyun Park、Kiho Kwak、Jihwan Bae、Wonsuk Lee

Smooth MPPIは、最適化後の操作列へフィルタを掛ける代わりに、操作の増分を探索して予測中の変化も評価します。滑らかな軌道の幾何と、実際の操作指令の滑らかさを分けて考えます。

確認日：2026-10-26、公式一次資料からHervarar上で新規に著述した独立再執筆版。対象はSmooth Model Predictive Path Integral Control without Smoothing、arXiv v8（2025-10-13）、§III–V・Algorithm 1と、公式コード固定版dcc6f42（2024-04-18）の選択処理です。原著の機構・評価とコードを静的に照合しました。全証明・付録・実験commit/重みの完全対応、著者コード実行、独立追試、現行車両への導入・学習・走行は未実施です。

1. 後から丸めると、評価した運動と変わる

MPPIは候補入力で未来を予測し、コストに応じて候補を重み付けします。得た操作を最後に平滑化すると、実際に送る操作は評価時の操作と変わります。急な減速や旋回が必要なときは、その遅れも問題になります。原著は外部フィルタによる操作変更を予測の外に置かず、探索する変数を一段持ち上げます。

uとaを区別することで、探索分布の入力コストとは別に、操作の変化を状態側のコストへ入れます。公開実装のcommand/noise_sampling/rolloutもUとaction_sequenceを別に保持し、差分コストと境界処理を持ちます。ただし固定版ではaction_sequence += Uという離散増分の実装です。原著のΔtを含む単位系と同一だと仮定してコードを移植しません。

4. 現行の滑らかな迂回経路とは、最適化する量が違う

探索空間現行ReferenceMppiは横方向の経路係数と曲率rolloutを探索する。SMPPIの操舵・速度の入力増分探索と同じではない。

評価と資源経路曲率、実操舵差分、加減速、追従誤差、衝突・停止、観測から適用までの期限超過を同時に測る。GPU性能だけで10 Hz成立を判断しない。

現行SLAM MPPI（確認基準commit）は静的占有を検査し、未知領域を禁止します。形の滑らかさを持つことから、操作の全周期の滑らかさ、動く相手への回避、安全保証までは導けません。停止監視を含む下流との契約を保った限定比較が必要です。
