論文詳解・独立再執筆2022 / 2023

MAP：必要な横加速度を、タイヤモデルから操舵へ変える

Jonathan Becker、Nadine Imholz、Luca Schwarzenbach、Edoardo Ghignone、Nicolas Baumann、Michele Magno

MAPはPure Pursuitに近い参照点追従を保ちつつ、横加速度から操舵角への変換へタイヤの振る舞いを入れます。経路を作る研究と、与えられた経路を追う研究を分けます。

確認日：2026-10-26、公式一次資料からHervarar上で新規に著述した独立再執筆版。対象はModel- and Acceleration-based Pursuit Controller for High-Performance Autonomous Racing、arXiv v4（2023-07-07）、§III–IVと、公式コード固定版5cce331（2023-07-10）の選択処理です。原著の機構・評価とコードを静的に照合しました。全証明・付録・実験commit/重みの完全対応、著者コード実行、独立追試、現行車両への導入・学習・走行は未実施です。

1. 幾何から決めた操舵だけでは、横滑りを表せない

Pure Pursuitは前方の参照点へ向かう曲率から操舵角を求めます。タイヤが横滑りする速度域では、同じ操舵でも幾何モデルどおりに曲がるとは限りません。MAPはまずL1 guidanceで必要な横加速度を求め、その値と速度を、車両・タイヤモデルから生成したlookup table（LUT）へ渡します。

2. 二つの変換を分けて考える

表1　原著式2–4・§III-Cの役割
関係意味と条件
a꜀ = 2 vₜ² sin(η) / Ld参照点までの距離Ld、速度ベクトルとの角度ηから横加速度を求める。
Pure Pursuit: δ = atan(a꜀ lwb / vₓ²)横滑りを無視する幾何的変換。実装では低速・零速度の扱いも必要。
MAP: δ = LUT(v, a꜀)同定した非線形タイヤモデルを使う。到達できない加速度や不安定な領域を含めて設計する。

原著は定常旋回で得るデータからPacejka型モデルを当てはめ、モデルの定常状態を数値計算してLUTを作ります。高操舵・高速度では定常解へ収束しない領域もあります。速度に応じたlookaheadは遅延と追従振動の折り合いを付けますが、全状態での安定性証明や周囲の障害物回避ではありません。

固定版MAP_controller.pyはwaypointの目標速度からlookaheadと横加速度を計算し、LUTへも目標速度を渡します。原著の速度ベクトルによる説明と、固定版の姿勢・目標速度を使う具体化を区別します。lookup処理は近い速度列を選び、加速度方向で補間します。速度方向まで連続的に補間すると想定しません。

3. F1TENTHの実機評価にも、条件の違いがある

表2　原著§IVと計算時間の条件
対象評価条件・読める範囲
速度scale比較同じglobal trajectory、60%速度で各controllerを調整後、2.5%刻みで上げ、各速度10周。RMS横誤差とlap timeを比べる。
タイヤモデル比較70/80%速度で5周。設営上trackを変更したため、前の速度scale実験とlap timeを直結しない。
計算負荷原著はJetson NXの単一ARMv8 CPU coreで1 cycle 6 msと報告。現在のPC・ROS通信・観測遅延を含む測定ではない。

原著の最高速度や代表誤差は、全比較行を同時に満たす保証値ではありません。HTMLでは単位の「/s」が抜ける箇所があるためPDFを照合しました。本記事では異なるtrack・速度条件をまとめた速度対誤差の順位表を作りません。既存台帳のv2（2023-04-25）を保全し、確認版v4を同じ研究系列の別資料として追跡します。ICRA 2023の刊行と初稿2022-09-09を区別します。

4. 現行の速度補償は、同定済みタイヤLUTとは違う

表3　現行方式との接続境界
観点現状と必要な作業
経路と制御MAPは与えた軌道を追うcontroller。TimePathの軌道予測やMPPIの迂回経路生成を置換する研究ではない。
車両・教師データ現行の有効応答長と操舵変換には速度補償があるが、MAPの自車タイヤ同定・LUTではない。重量、慣性、タイヤ、路面、遅延を別に測る必要がある。
再学習・検証認識モデルの再学習を必須とはしない。LUT生成と同定用データ、範囲外/低速/操舵飽和、追従・停止・期限の検証が必要。実車同定走行は今回の範囲外。

現行の幾何baselineと現行の車両応答変換を静的確認しました。後者は静的wheelbase、速度依存応答長、actuator gainを区別します。固定値の存在をタイヤ摩擦の実測結果や高速域検証の代用にしません。公開repoの同梱simulatorも線形タイヤモデルの比較用で、論文実機の非線形タイヤ実験が自動的に再現されるわけではありません。

確認範囲と関連資料

書誌・版履歴、v2/v4の選択機構・評価・PDF単位、公式README、controller・lookup・生成scriptを確認。全版の同一性、全同定・実験データ、recipe対応・独立再現は未確認です。ForzaETH Race Stack、On-Track SysID、レーシング概説、研究地図。

操舵への変換と、速度の余裕を分ける

2026-10-26追記。Adaptive Velocity Planningは位置ごとの安定性指標を速度profileへ戻す研究です。MAPの操舵LUTを更新する処理とは異なり、併用する場合も速度と操舵の整合・遅延・停止を別途検証します。独立追試・現行車両への導入は未実施です。
