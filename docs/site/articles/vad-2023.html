論文詳解・独立再執筆2023

VAD：道路と相手をベクトルで表し、軌道の学習へつなぐ

Bo Jiang、Shaoyu Chen、Qing Xu、Bencheng Liao、Jiajie Chen、Helong Zhou、Qian Zhang、Wenyu Liu、Chang Huang、Xinggang Wang

VADは相手の未来軌道と地図要素をベクトルとして予測し、自車の軌道学習へ接続します。学習時の制約損失、ログ上の衝突指標、実行後の閉ループ評価を区別します。

確認日：2026-10-26、公式一次資料からHervarar上で新規に著述した独立再執筆版。対象はVAD: Vectorized Scene Representation for Efficient Autonomous Driving、arXiv v3（2023-08-24）、§3–4・Tables 1–5と、公式コード固定版1688c4b（2026-01-31）の選択処理です。原著の機構・評価とコードを静的に照合しました。全証明・付録・実験commit/重みの完全対応、著者コード実行、独立追試、現行車両への導入・学習・走行は未実施です。

1. 密な画像表現から、物体と線の単位へ

カメラ特徴からBEV特徴を作り、agent queryで相手の属性・未来軌道を、map queryで道路境界やlane dividerなどの点列を予測します。自車のqueryは相手・地図とのattentionを経て、ナビゲーション情報とともに将来軌道を出します。ベクトル化はBEV特徴抽出を消すという意味ではなく、planningに渡す場面表現を物体・線の単位にする設計です。

2. 制約は学習目的の中にある

表1　原著§3.3–3.4のplanning損失を簡略化
関係・項目作用
Lplan = Limi + Lcol + Lbd + Ldir模倣と3種の制約損失を組み合わせる役割の表記。全損失の重み・map/motion学習は省略。
collision / boundary相手の予測軌道との距離と道路境界への接近を罰する。相手の全将来分岐を保証対象にするものではない。
lane direction近傍lane dividerの向きを自車の移動方向の事前情報に使う。誤認識や特殊な道路形状は別途検証が必要。

原著の衝突損失はconfidence thresholdでagentを選び、多峰予測から最高confidenceの軌道を使います。固定版plan_loss.pyではこれらを学習損失として実装しています。Safety Filterのように毎時刻制約付き最適化を解いてから操作を許可する機構だとは扱いません。公式repoはVAD v1/v2を併載していますが、今回確認したのはprojects/.../VAD側のv1関連処理で、VADv2を本論文の成果へ混ぜません。

3. 開ループと閉ループの結果を分ける

原著は2秒の履歴から3秒先を計画します。nuScenes valでは記録済みの世界に対してL2距離とcollisionを測り、主比較ではshortcut learningを避けるためego status特徴を外します。CARLA Town05では操作を環境へ戻す別評価を行い、navigationや信号認識を追加します。二つは同じ入力・評価契約ではありません。

表2　原著Tables 1・4・5からの限定値
条件原著の値比較上の境界
nuScenes、VAD-Base、ego statusなし平均L2 0.72 m、平均collision 0.22 %（Table 1）1/2/3秒の平均。実走行の事故率ではない。
CARLA、VAD-BaseTown05 Short: DS 64.29 / RC 87.26。Long: DS 30.31 / RC 75.20（Table 4）DSとRCを成功率へ置換しない。LongではLiDAR系TransFuserのDS 33.15より低い。
VAD-Tiny、RTX 3090×159.5 ms（Table 5のmodule合計）Baseの224.3 msやUniADの別GPU測定と混同しない。実センサから操作適用までの遅延ではない。

固定版のmetricではGT軌道側が衝突する時点を除くマスクや、点と車体boxの衝突集計を区別します。したがってcollisionの値には実装・有効mask・分母が関係します。Table 1の全指標とこの固定commitの実験設定・重みを完全に対応付けたわけではなく、他手法や現行車両との順位表には転用しません。

4. 現行TimePathに加える対象は、出力点数よりも教師と場面表現

表3　現行方式との違いと必要な検証
観点接続候補・未検証点
観測と教師現行Camera + 2D LiDARの契約に、VADの複数camera、較正、vector map、agent追跡・未来ラベルをそのまま仮定しない。必要な教師生成と欠損処理を定義する。
出力と再学習同じ3秒の軌道でも座標・間隔・command条件が異なる。query/損失の追加はモデル変更と再学習を伴う。GT futureは評価・教師に限定する。
検証と資源nuScenesの指標再実装を照合したうえで、相手が反応する閉ループ、認識落ち、境界外、停止・再発進、遅延とGPUメモリを測る。

現行TimePathV1は0.1秒間隔30点のXYを出す設計です。現行の静的占有plannerにはVADのagent未来予測・vector map queryはありません。現行の停止監視も維持し、学習損失の追加を一般的な安全保証として公開しません。
